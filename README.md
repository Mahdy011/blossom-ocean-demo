# Blossom Océan — concept de démonstration

Site vitrine responsive HTML/CSS/JavaScript, sans framework et sans coût d'hébergement.

## Ouvrir dans VS Code
1. Décompressez `blossom-ocean-demo.zip`.
2. Ouvrez VS Code → File → Open Folder → sélectionnez `blossom-ocean-demo`.
3. Ouvrez `index.html` dans un navigateur (double-clic depuis l'Explorateur Windows).
4. Pour un aperçu plus pratique dans VS Code, installez l'extension Live Server, puis clic droit sur `index.html` → Open with Live Server.

## Fichiers
- `index.html` : contenu et sections du site.
- `style.css` : design, responsive mobile et animations CSS.
- `script.js` : menu mobile et animations au défilement.

## Avant de présenter / publier
- Il s'agit d'une maquette non officielle. Ne la présentez pas comme le site officiel de Blossom Océan.
- Les photos de café, plats et intérieur ont été ajoutées à partir des images que vous avez fournies. Les captures de menus sont des images de référence.
- Les plats et prix sont des exemples/placeholders. Confirmez le menu, les tarifs, les horaires et les coordonnées avec l'établissement avant publication.
- L'adresse et le téléphone affichés ont été trouvés dans des annuaires publics et doivent être revérifiés avec l'entreprise.
- Remplacez les photos par des images autorisées par le restaurant avant livraison.
- La démo utilise Google Fonts et des images externes, donc Internet est nécessaire pour afficher les polices et photos.

## Publication gratuite sur GitHub Pages
1. Créez un dépôt GitHub public, par exemple `blossom-ocean-demo`.
2. Envoyez les trois fichiers `index.html`, `style.css`, `script.js` à la racine du dépôt.
3. Dans le dépôt : Settings → Pages.
4. Sous Build and deployment, choisissez Deploy from a branch.
5. Branch: `main`, folder: `/ (root)` puis Save.
6. Attendez le déploiement et ouvrez l'URL affichée dans Settings → Pages.
